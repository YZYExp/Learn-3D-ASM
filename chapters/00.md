# 导读：造物的加减法

## 从3D打印，走进材料变成物体的世界

![AI教学示意：层纹花器、树脂抽象造型、晶格支架与铣削铝件。这里展示视觉语言，不代表真实产品。](../assets/images/01-cover.jpg)



一卷线、一槽液体、一层粉末，最后竟然能成为灯罩、牙模、机械夹具或火箭部件。3D打印最迷人的地方，是它把“想出来的形状”变成了可以拿在手里的东西。但真正值得读懂的，还包括它为什么有层纹，为什么某些方向容易断，为什么金属件打印完还要送去机床。

这本书把3D打印放在中心。先认识主要打印工艺，再认识材料、制造流程和表面语言；随后把车、铣、磨、电火花和切割放进同一张地图。最后走近当代品牌、工程团队与创客社区，看看一项工艺怎样变成可用的产品与服务。

## 可以这样读

第一次接触制造，按章节顺序读即可。已经有桌面打印机，可以从第02章、第07章和第08章开始；喜欢工业设计与漂亮物件，可先翻第11章，再返回工艺部分；希望认识行业，则把第12至15章连起来读。品牌不是排行榜，技术与商业状况也不会因为一本书写下名字就停止变化。

正文使用三种图像：**AI教学示意**展示质感、造型和对照设想；**原创图解**解释经过核对的分类与结构关系；**真实来源图片**展示可追溯的设备、工作环境和应用。AI图中的作品是概念设计，不能据此推断某种材料已经通过承载、透明度或制造可行性验证。

每个关键事实旁保留来源。PDF页脚列出当页用到的资料，点击资料标题可打开来源；工程包包含分章Markdown、图片出处和构建脚本。正文中的“观察练习”是帮助理解的思想实验，不需要先买设备。

## 带着一个任务来读

同一种工艺会出现在不同产业，同一个物件也可能经过几种工艺。下面从任务找入口；读到案例后，再回头看原理，会更容易理解那些取舍。

| 你想解决的任务 | 从哪里读起 | 看案例时抓住什么 |
|---|---|---|
| 给工位做定位、装配或检查工具 | 第02章：材料挤出 | 接触面、方向性，以及磨损后怎样更换 |
| 做牙科模型或珠宝铸造型 | 第03章：光固化 | 打印的是中间工具，还是最终使用件 |
| 做复杂尼龙零件或定制足矫形器 | 第04章：SLS与MJF | 清粉、尺寸和用户适配怎样完成 |
| 做复杂金属流道或修复局部磨损 | 第05章：金属增材 | 内部几何为何值得打印，哪些位置还要加工 |
| 表达多材料外观、埋入元件或成形陶瓷 | 第06章：特殊工艺 | 是外观原型、生坯，还是交付状态的功能件 |
| 从零做一个可装配的小外壳 | 第07、08章：材料与流程 | 怎样用局部试片发现问题，再改版 |
| 做轴套、精密模具或切割板材 | 第09章：减材 | 旋转、刀具、放电与切割分别适合哪些特征 |
| 让打印结构获得准确安装面 | 第10章：混合制造 | 加工余量、装夹基准和最终检验 |
| 为自己的项目写出制造选择 | 第16章：练习 | 把需求、路线、失败原因和证据写在同一张卡上 |

书中的案例会注明证据身份：**真实项目**来自可追溯的企业、机构或客户资料；**典型工程应用**解释一类任务，不假装发生在某家工厂；**作者教学练习**用于演示如何做决定。企业案例能说明一条路线怎样被采用，不能单独证明它适用于所有设备、材料与使用条件。案例中的真实图片与原创示意也分别标注。

## 本书的时间与边界

品牌资料检索截至2026年10月22日。公司归属、产品系列和开源政策以标注日期的公告及当前官方文件为准；并购“宣布”和“交割”分开记述。本书不以促销价格和一组未经复测的速度数字来比较机器。

这是兴趣科普读本。材料名称是一条入口，而不是完整性能承诺；一个漂亮零件的背后，还可能有清洗、热处理、精加工和检验。学会看见这些被成品照片隐藏的过程，就能更准确地理解制造。
