# 附录：把缩写翻译成看得见的动作

| 名称 | 中文与含义 | 读到它时先问什么 |
|---|---|---|
| AM | 增材制造 | 属于哪种成形原理？ |
| FFF / FDM | 熔融丝材制造／熔融沉积建模 | 送料、热端、腔体与材料是否匹配？ |
| SLA | 立体光刻，常用于激光扫描槽式光固化 | 光源怎样扫描，后固化怎样做？ |
| DLP | 数字光处理，常用于投影式光固化 | 曝光面积、光学与材料条件是什么？ |
| MSLA | 掩膜式立体光刻，常见LCD掩膜方案 | 像素、光学、曝光与真实尺寸表现如何关联？ |
| SLS | 选择性激光烧结 | 用什么粉末，冷却与清粉怎样做？ |
| MJF | HP的Multi Jet Fusion | 用什么助剂与热能，为什么不是喷胶生坯？ |
| LPBF | 激光粉末床熔融 | 合金、热过程、支撑与检验怎样组织？ |
| PBF-EB / EB-PBF | 电子束粉末床熔融 | 真空与预热条件如何影响应用？ |
| DED | 定向能量沉积 | 送粉还是送丝，成形后要加工哪里？ |
| BJ | 粘结剂喷射 | 打出来是生坯还是最终材料状态？ |
| MJ | 材料喷射 | 喷出的是成形材料还是助剂？ |
| CNC | 计算机数控 | 指控制方式，实际执行哪种加工？ |
| CAM | 计算机辅助制造 | 刀具、装夹与路径是否合理？ |
| EDM | 电火花加工 | 工件导电吗，是线切割还是成形电极？ |
| CAD | 计算机辅助设计 | 模型是否表达完整的制造需求？ |
| STL | 常见三角网格交换格式 | 单位、网格、封闭性是否正确？ |
| 3MF | 3D Manufacturing Format | 软件实际保留与交换了哪些信息？ |
| DfAM | 面向增材制造的设计 | 形状、材料、方向与后处理是否一起设计？ |
| TDS / SDS | 技术数据表／安全数据表 | 性能适用条件与处理要求分别在哪里？ |

这些词汇是全书的回查索引，具体定义与限制请回到对应章节及其资料。厂商可能使用专有名称，不能仅靠字母相似判断工艺等同。

## 想继续读，可以从这里出发

- 看工艺分类与测量：NIST Additive Manufacturing Technologies，https://www.nist.gov/additive-manufacturing/research-areas/technologies 。
- 看桌面材料与打印问题：Prusa Knowledge Base，https://help.prusa3d.com/ 。
- 看树脂与后处理：Formlabs Learning Resources，https://formlabs.com/blog/ 。
- 看金属材料体系：EOS Materials，https://www.eos.info/metal-solutions/metal-materials 。
- 看切削与刀具：Sandvik Coromant Knowledge，https://www.sandvik.coromant.com/en-gb/knowledge 。
- 看文件交换的技术目标：3MF Consortium，https://3mf.io/ 。

这些是阅读入口，不代表对某一品牌所有宣传的认可。阅读具体性能和应用时，仍应回到相应设备、材料版本及测试条件。
